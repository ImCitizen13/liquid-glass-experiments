# Liquid Glass Experiments

A repository for iOS experiments exploring Apple's Liquid Glass design system in SwiftUI.

## Features

- Interactive fan petal animations with multiple animation styles (Fan, Bloom, Stack)
- Liquid Glass effects with customizable tint opacity
- Draggable and scalable glass petal compositions
- Dynamic background image switching

## Requirements

- Xcode 26+
- iOS 26+
